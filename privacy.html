Privacy Policy

Effective Date: November 25, 2026

Shorts Automation respects your privacy. This policy explains how data is handled when using our desktop TikTok publishing tool.

1. Data Collected

We only store TikTok OAuth access/refresh tokens and basic account identifiers (open_id) locally on the user's own computer with restricted file permissions (0600) solely to authenticate API upload requests.

2. Data Sharing

No user data, tokens, or analytics are sold, shared, or transmitted to third parties other than the official TikTok Open API endpoints.

3. Data Deletion

Users can delete all stored credentials locally at any time and revoke app permissions directly within TikTok settings.
